# DSH Starter v0.1.0 发布说明

发布日期：2026-09-20
GitHub Release：https://github.com/Yinxe/dsh-starter/releases/tag/v0.1.0

> 本文件由 `npm run notes:archive` 从 CHANGELOG.md 生成，请勿手改。

首个公开版本。

### 新增

- **版本与安装**：从 npm registry 拉取 `@deepseek-ai/dsh` 的全部已发布版本（dist-tag、发布日期、体积，镜像可切换），
  一键安装 / 卸载 / 重装到启动器自己的数据目录；同时识别启动器安装、npm 全局安装、PATH 中的 `dsh` 三种来源并合并展示。
- **Node 运行时**：宿主机没有 Node 时可一键安装隔离的 Node LTS（用户级、无需 root、不污染系统），下载默认走镜像站。
- **三种启动方式**：内嵌子进程（日志实时回传「实例终端」）、独立进程（关闭启动器后 dsh 继续运行）、系统终端（交互式 TUI）。
- **Profile 管理**：扫描 `$DSH_HOME/profiles` 并选择启动；profile 卡片可折叠出 web 快捷配置与 patch 编辑；
  支持重命名、复制实例（自动错开 web 端口）、删除与回收站（可还原）、以及用 dsh 自带模板新建「恢复模式」。
- **每 profile 单实例**：内嵌与终端/外部启动的实例都会被识别，重复启动与端口占用都会给出可操作的错误提示，而不是让 dsh 秒退。
- **实例观测与停止**：独立进程 / 外部实例的发现、运行时长与日志查看、日志导出、统一的停止入口。
- **插件管理**：全链路走官方 `dsh plugin` 命令，内置终端流式输出、失败任务重试、GitHub 直装前核对构建产物；
  dsh 自带的 base / web-app / headless 禁止卸载与启停。
- **模型与凭据**：结构化编辑 `settings.yaml` 的 providers / agent-default-model 两节（支持 K/M 简写），凭据单独管理。
- **应用内更新**：检查 / 下载 / 验签 / 安装 + 重启，默认只在用户点击后执行；另有「自动下载安装」开关供愿意全自动的用户开启。
- **界面与托盘**：shadcn/ui + Tailwind CSS v4 全套组件、亮暗主题（默认跟随系统）、无边框自绘窗口外壳、
  侧栏可折叠的响应式布局；托盘常驻，左键切换窗口，右键查看各 profile 运行状态，关闭默认最小化到托盘。

### 修复

- dsh 启动约 10 秒后被强制停止（PDEATHSIG 误杀子进程）。
- 版本比较器语义反转导致「可升级」误判。
- profile 目录改为 `$DSH_HOME/profiles`（复数）并跳过 `node_modules`。
- 插件 ID 误报、插件页 profile 下拉被字母序抢占（应为 `web`）、正式版筛选把 RC 当成预发布。
