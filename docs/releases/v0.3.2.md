# DSH Starter v0.3.2 发布说明

发布日期：2026-09-24
GitHub Release：https://github.com/Yinxe/dsh-starter/releases/tag/v0.3.2

> 本文件由 `npm run notes:archive` 从 CHANGELOG.md 生成，请勿手改。

### 变更

- **插件卸载只看官方命令的结果，配置清理改为卸载时可选**：此前 profile 的 `cordis.patch.yml` 里只要还引用着这个插件，卸载就会被硬拦下报「无法卸载」——但官方 `dsh plugin remove` 本来就不负责维护补丁层的插件数据，这个拦截只会把用户卡在原地。现在只要官方命令把包从依赖声明与 bundles 里卸干净就算卸载成功；卸载确认框新增「同时清理插件在 cordis.patch.yml 中的配置」开关（**默认开**）：成功后启动器按行删掉该插件在补丁文件里的条目（禁用块、按 name/id 挂的配置、`insert:` 挂载项都在范围内），文件其余内容与注释逐字不动，原件备份为 `cordis.patch.starter-bak`；删不干净的形态（如 flow 写法）会在终端里如实提醒去「配置文件」Tab 手动确认。该清理只作用于 0.1.7+ 的 profile 配置，旧版的全局 `settings.yaml` 由 dsh 自己维护、卸载不触碰；关掉开关则完全不动补丁文件，只提示去哪手动删。

### 修复

- **Linux：应用内打开的 dsh web 界面可以使用麦克风了**：此前 WebKitGTK 不会把网页的麦克风/摄像头（getUserMedia）权限请求放行，语音输入始终提示「麦克风权限未开启，请在浏览器和系统设置中允许访问」。现在启动器对这类请求自动批准（与 macOS/Windows 行为一致），地理位置、系统通知等其他权限仍默认拒绝。
