# DSH Starter v0.2.0 发布说明

发布日期：2026-09-21
GitHub Release：https://github.com/Yinxe/dsh-starter/releases/tag/v0.2.0

> 本文件由 `npm run notes:archive` 从 CHANGELOG.md 生成，请勿手改。

> **这一版换了名字，也换了「身份证」。** 程序改名 **DSH Starter**（旧名 `DSH Launcher` 里的
> `luncher` 是个不存在的词），应用标识从 `com.deepseek.dsh-launcher` 变成 `com.deepseek.dsh-starter`。
> 系统按标识认程序，于是新旧两版会被当成**两个程序**：应用内更新会把新版正常装上，但 Windows 的
> 「应用和功能」里可能同时出现新旧两条，装好后请手动卸载旧版。
> **设置、已装版本、profile、凭据都不用重新配置** —— 首次启动会自动搬迁（见下）。

### 变更

- **改名 DSH Starter：仓库、下载页、安装包与数据目录全部统一，数据自动搬家不丢一份**：仓库变为 <https://github.com/Yinxe/dsh-starter>（旧地址访问会自动跳转），下载页变为 <https://yinxe.github.io/dsh-starter/>（**旧下载页地址不再跳转**，请更新书签），安装包文件名从 `DSH.Launcher_…` 变成 `DSH.Starter_…`，窗口标题与侧栏品牌名同步换成 Starter。启动器数据目录也从 `~/.dsh-launcher` 改名成 `~/.dsh-starter`，**首次启动时自动整体搬迁**：已装 dsh 版本、profile、设置、日志与凭据原样保留（同一磁盘上是改名而非复制，几百 MB 的 `versions/` 也是瞬间完成）。万一目录被占用或跨盘搬不动，程序会继续使用旧目录并在启动日志里说明原因 —— **宁可名字不一致，也不会让你以为数据丢了**。
- **旧备份与旧标记继续被认作「自己的东西」**：启动器覆写 `package.json` / `cordis.patch.yml` / 凭据文件前生成的那份备份，后缀从 `*.launcher-bak` 改成 `*.starter-bak`，但**老备份会被自动接手改名** —— 不会被当成「还没备份过」而重新生成一份、把你原始的干净版本挤掉；写进 profile 的 `# dsh-launcher: disable` / `web-quick` 标记也继续被识别，之前关掉的插件照样能正常开回来，不会在配置里留下一堆删不掉的块。按时间戳堆积的旧备份（`*.launcher-bak-<时间>`）与旧版一样会被自动清理。
- **主题选择不会因为改名被重置**：亮/暗色的存储键换了，但读取时会回落到旧键，你之前选好的主题照旧生效。
