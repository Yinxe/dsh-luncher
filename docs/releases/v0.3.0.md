# DSH Starter v0.3.0 发布说明

发布日期：2026-09-22
GitHub Release：https://github.com/Yinxe/dsh-starter/releases/tag/v0.3.0

> 本文件由 `npm run notes:archive` 从 CHANGELOG.md 生成，请勿手改。

### 新增

- **侧栏「项目仓库」卡片新增 QQ 用户群入口**：卡片底部多出一枚「QQ 群 1067778060」按钮，点一下即复制群号，去 QQ 搜群号加群反馈问题、交流插件；侧栏折叠成图标栏时也有对应的图标按钮（悬停显示群号）。
- **侧栏新增「系统日志」页：应用内直接排查问题，不用再去翻日志文件**。9 类系统日志（app / instance / install / runtime / plugin / profile / network / ui / panic）按分类一页浏览：分类标签实时显示文件大小，尾部内容自动滚到最新，支持按级别（DEBUG/INFO/WARN/ERROR）与关键词过滤、2 秒自动刷新跟随输出、一键复制本屏。**日志可在页内一键清除**：「清除此分类」「全部清除」二次确认后删除当前与滚动出的日志文件并回收磁盘，日志系统下次写入自动重建（建议先「生成诊断包」再清）。**日志级别在页内下拉即选即生效、无需重启**（保存到设置；高级用户仍可用环境变量 `DSH_STARTER_LOG` 强制覆盖，此时页面会标出「环境变量锁定」）。原先只藏在设置抽屉里的「打开日志目录」「生成诊断包」两个按钮也挪到了这一页；「生成诊断包」现在直接在弹窗里展示全文（顶部**一键复制全文**、打开所在目录），报 bug 时不必再去文件夹里找文件。设置抽屉对应位置留下指向新页的说明。
- **全局命令面板（⌘K / Ctrl+K）**：侧栏新增「命令面板」入口按钮，或随时按 ⌘K（Windows/Linux 为 Ctrl+K）呼出居中搜索面板——输入关键词即可在**导航**（首页、版本与安装、Profile 实例、插件管理、模型配置、配置文件、凭据管理、统计、系统日志 9 个页面）、**操作**（打开 DSH 主界面、按 profile 启动/重启/停止、刷新实例与版本清单、检查启动器更新、开关实例终端、打开设置）与**外观**（深色 / 浅色 / 跟随系统）之间快速跳转执行，↑↓ 选择、Enter 执行、Esc 关闭，不用再去各页面上找按钮。
- **凭据管理防外部覆盖**：凭据页读取文件后，如果 `.credentials.yaml` 被运行中的 dsh 或其它程序改过（或删除），此时点「保存」会**检测到不符并拒绝写入**，提示先「还原」载入最新内容再重新编辑 —— 不再出现「后保存的人静默覆盖先写入内容」。凭据读写也移出主线程，大文件不再卡顿界面。
- **DSH Web 界面支持应用内独立窗口打开，像桌面版一样没有浏览器套壳**。顶栏「打开 DSH 界面」、首页、实例列表与实例终端的「打开」现在默认在应用内新窗口中呈现实例的 Web UI：没有地址栏、标签页；一个地址只对应一个窗口（再点是把已有窗口聚焦，不会越开越多），多个实例同时运行可以各开一个窗口并排使用。Profile 页新增「打开方式」单选（独立窗口 / 系统默认浏览器），随时可切回浏览器打开，全局生效。
- **配置文件编辑：语法错误一律拦在保存之前**。「配置文件」「插件管理」「Profile 配置」三处 YAML 编辑器现在共用同一套校验：写坏的 YAML 不仅在编辑器里行内标红，编辑器下方还会列出「第 X 行 第 Y 列」的具体错因，**保存按钮直接禁用**（悬停提示原因），改对了才会亮起并给出「语法校验通过，可保存」的确认；Tab 缩进这类 serde_yaml 必拒的写法也会被当场标出。保存快捷键 Ctrl/Cmd+S 顺手可用。后端写盘前的权威校验同样升级：报错带上出错行列，不用再从头数哪一行写坏了。
- **侧栏新增「统计」页：本机 dsh 的 Token 用量与在线时长一目了然**。读取本机会话日志（只读，不碰 dsh 任何配置）聚合出：全历史总览（总/输入/输出/缓存 Token、请求数、活跃天数、连续使用打卡、峰值日、最大单请求）、近 7/30/90/365 天按日模型堆叠趋势（鼠标悬浮即出当日合计与各模型明细）、今日 24 小时分布、Token 活动热力图（绿色阶、默认 6 个月可切 12 个月、自适应宽度不溢出、低用量日也清晰可见，悬浮出当日总消耗/输入输出/缓存读写/最忙模型明细）、模型用量分布卡（环形图 + 全模型响应式网格，悬浮看输入/输出/缓存构成）。口径与社区插件 token-meter 完全一致（含 fork/resume 会话去重），首次全量扫描后按文件指纹增量缓存（存在 `~/.dsh-starter/session-stats-cache.json`，可随时删除重建），之后秒开。「在线时长」标签按事件时间间隔判定在线：相邻事件间隔不超过阈值即算同一段在线，「空闲阈值」卡里 1/5/15/30/60 分钟五档并排显示各档累计与相对当前档的增量（推荐 15 分，切档秒出不用重扫），并给出「时间范围」（近 14/30/90 天/全部）只作用于每日图表；今日在线、累计在线、活跃日均、对话进行中、模型生成、工具执行、引擎合计逐项标注「精确 / 估算 / 下界」口径，底部「口径与准确性」表逐条解释每个数字怎么算、能信到什么程度；时长一律按小时显示。「分享」按钮把全历史总览、在线时长、模型用量分布按响应式版式（随窗口宽度自动降列）生成 2× 高分辨率 PNG 报表，一键复制到剪贴板或下载，直接发图。
- **侧栏新增「首页」（菜单第一项，打开应用即停留在此）**：一张卡片搞定 DSH Web 的一键启动/停止/重启/打开界面，实时显示运行状态与访问地址，窄窗口下按钮自动换行不叠字；dsh 还没初始化时该页直接给出初始化引导。
- **「一键安装 Node」现在会核对官方 SHA-256**：内置 Node 的归档下载完不再只看文件头 —— 程序边下载边计算 SHA-256，和 Node.js 官方发布的哈希逐字节比对，不一致就删掉这半份文件并告诉你「换镜像站重试」。镜像站被劫持、网关塞给你一份「长得像安装包」的文件，从这一刻起都会被拦下。
- **Profile 记住自己的启动版本，换版本启动前先让你确认风险**。每个 profile 现在会记录上一次真正把它跑起来的 dsh 版本（Profile 实例页与首页在未运行的行上显示「上次 dsh x.y.z」）；如果你切换了「当前版本」，再用一个不同的版本去启动它 —— 升级或降级都一样 —— 不再直接拉起，而是先弹出风险确认框，列明「上次成功启动 / 本次将启动」与方向（升级 / 降级），并说清插件不兼容、配置格式对不上可能让这个 profile 起不来，降级还可能遇到新版本写过的配置旧版本读不了。取消则不启动、记录不变；点「已知风险，继续启动」即启动，并把它记为新的绑定版本，同样的版本组合之后不再重复提示。从没启动过的 profile 首次启动不打扰。启动器拉起的实例活过 15 秒才会被记为「这个版本跑得起来」，所以一启动就崩掉的版本不会把提示静默掉。记录保存在 `~/.dsh-starter/profile-versions.json`，随 profile 改名 / 删除同步维护。

### 变更

- **新装用户的默认启动方式改为「独立进程」（后台常驻）**：现在点「启动」拉起的 dsh 不再随启动器退出而结束 —— 关闭或退出启动器后 DSH 继续运行，重开启动器自动扫描识别，「实例终端」里可看它的日志尾部（日志在 `~/.dsh-starter/instance-logs`）。Profile 页的「启动方式」仍可选回「子进程」（日志实时回传实例终端、退出启动器即结束所有 dsh），已保存过启动方式的老用户不受影响。
- **关键路径全部补上日志留痕：出问题能定位到「哪一步卡住」**。此前分类日志只覆盖一部分链路，现在设置读写与凭据保存（只记键名、绝不记值）、profile 配置与模型配置写盘、dsh 安装成功/取消清理/卸载与 profile 绑定版本变更、应用内更新下载验签、终端启动、插件清单修复，一直到每一次 registry / GitHub API / 模型列表请求 —— 含网络通道连续失败后的临时停用与恢复、API 额度耗尽 —— 都会落进「系统日志」页对应的分类文件。下次遇到「装不上 / 保存没反应 / 更新日志打不开」，生成诊断包就能看清失败发生在哪一步、哪条通道、什么错误。
- **README 与下载页的界面预览扩充为三张**：新增「Profile 实例 + Web 界面独立窗口」与「统计页（Token 热力图与模型分布）」两张深色主题截图；下载页「界面长这样」区块改为三张图依次展示，特性卡片同步换成「版本与安装 / Profile 实例 / 统计」。
- **托盘菜单精简为「打开主界面 / 退出」两项**：不再列出各 profile 的运行状态（● 运行中 / ○ 未运行），右键菜单更短更干净；实例状态仍可在主界面的 Profile 页查看。
- **凭据页交互全面提舒**：切到别的页面再回来，未保存的凭据编辑不再丢失（以前整页重置）；「还原」在有未保存修改时先弹出确认并列明改动数（新增 x · 修改 y · 删除 z），不再一键静默丢草稿；Ctrl/Cmd+S 直接保存；保存按钮与顶栏徽标实时显示「N 处修改」；凭据较多（≥8 条）时列表头部出现按名称/注释的即时过滤框；顶部大段规则说明收进一行可展开的折叠条，不再常驻占屏；空值凭据标出橙色「空值」徽标；双击行即开详情；添加/编辑弹窗里值超过 64KB 当场提示并禁止提交；中文输入法回车选词不再误触发提交。
- **标题栏不再重复品牌**：窗口最上方那条标签栏去掉了 logo，只留居中显示的「DSH Starter」——过去它和侧栏头部的 logo + 产品名上下叠着，两个图标两张名字。
- **侧栏「运行状态」卡片改为按钮 + 弹出详情**：常驻的「运行状态 / 目录与源」大卡片收成一个「运行状态」按钮（带运行中实例数角标），点击后在侧栏旁边弹出 Popover 显示全部内容（状态灯、实例终端入口、路径复制、托盘提示）；侧栏折叠为图标栏时，四个状态灯同样可点击弹出详情，侧栏底部更清爽。
- **dsh 更新日志改为长期磁盘缓存，正常打开不再消耗 GitHub 额度**：以前这份缓存只活在进程里（10 分钟），重启启动器后第一次打开更新日志又要打一次 api.github.com（匿名一共 60 次/小时）。现在拉到的 Release 会存进 `~/.dsh-starter/dsh-releases.json` 并**长期复用** —— 重开应用、反复查看、断网或额度耗尽都能照常翻日志，一次请求都不发。官方发了新版本想看说明时，点更新日志右上角的「刷新」强制拉一次即可（这是唯一会打 API 的入口）。
- **视觉升级：黑灰鲸鱼标**：Logo 不再用 harness 专属的品牌蓝，换成「墨黑→石墨银」渐变（侧栏、标题栏、托盘与安装包图标一并重生成）。界面上的蓝色元素（Web 徽章、外部实例圆点、RC 渠道条、任务转圈）分别改为石板灰与青绿；卡片新增投影层次、选中文本染主色，亮色页底渐变略微加深，暗色主题保持原中性灰不变。
- **打包产物直链安装只接受 https**：填 `http://…/pkg.tgz` 这类明文直链过去会原样交给安装命令，压缩包在传输途中可以被中间人换成任何内容且无从察觉。现在安装前直接拒绝，并提示换成 https 链接。

### 修复

- **Linux 上「分享 → 复制图片 / 下载 PNG」不再报 `SecurityError: The operation is insecure`**：打包后的应用里页面运行在 `tauri://` 自定义协议上，WebKitGTK 会把导出用的 `blob:` 临时链接判为跨源、污染画布，编码 PNG 那一步直接抛安全错误（开发模式是普通 http 源所以碰不到，「以前能用」就是这么来的）。现在画布被拒时自动改用同源的数据内联链接重新光栅化，导出/复制恢复可用；内联样式里的外部字体 `url()` 也一并剥掉（字体在导出图里本就不生效、文字一直走系统回退，零视觉损失），消除另一处跨源污染来源。
- **版本确认放行后如果没起来，绑定不再被记成新版本**：在风险确认框点「继续启动」后，若因端口被占等原因启动失败，profile 的绑定版本保持旧值 —— 下次启动仍会提醒；原先确认即落库，起不来反而把这道闸门静默吞掉。绑定版本改在实例确实拉起成功后写入。
- **Profile 页实例列表不再因绑定版本读取失败而整体停更**：该读取失败时降级为空清单继续展示，3 秒轮询不会连累实例状态一起卡死。
- **系统日志页三处体验修正**：快速切换分类时旧分类的响应不再落到新分类页签下；上翻阅历史时自动刷新不再每 2 秒把视线拽回底部；超长日志只渲染最近 800 条并给出提示，低配机器不再整屏卡顿。清除日志部分分类失败时，报错里也会说明其余分类已释放的字节数。
- **Web UI 独立窗口支持 IPv6 地址**：`http://[::1]:8080` 这类地址过去会因窗口名含非法字符而打不开；现在 http 与 https 同 host 端口也各自独立成窗，聚焦旧窗口不再错开成另一个协议。
- **各配置页连按 Ctrl/Cmd+S 或狂点保存不再并发写盘**：全局配置、插件、Profile 补丁与凭据保存都加了在途守卫；凭据页在任一弹窗打开时按 Ctrl+S 不再误保存底下的列表。
- **诊断包弹窗长日志不再顶穿标题**：日志很长时弹窗会被撑得比屏幕还高，正文滚到最上面时会盖住标题和「复制全文」按钮。现在弹窗最高只占屏幕 85%，正文在自己的区域里滚动，标题与操作按钮始终可见。
- **凭据保存不再因注释里的制表符/回车报「内部错误」**：注释里混进控制字符（如从别处粘贴）时，过去会生成非法 YAML 被写盘前校验拦下，用户只看到一句看不懂的「内部错误」。现在这些字符在写入前就被压成空格，注释始终是一行干净文本；凭据名称的长度限制也统一为按字符数计（含中文的名称不再前端放行、保存被拒）。
- **配置编辑器的「还原」不再在最需要它的时候被禁用**：过去有未保存修改时还原按钮反而灰着（`disabled={busy || !dirty}`），而把文件写坏之后最想做的恰恰是丢弃改动、读回磁盘版本。现在有错随时可还原，未保存改动也能一键丢弃。
- **desktop profile 被认错成 Web**：dsh 内置的 `desktop` profile 里同时带着 `@deepseek-ai/dsh-web-app`（桌面外壳内嵌 Web 界面），过去只看 bundles 会把它标成 `Web` 标签。现在先认 package.json 的 `name`：`@deepseek-ai/dsh-desktop-runtime` ⇒ `Desktop`，标签回到正确的桌面形态（桌面启动方式仍将在后续版本支持）。
- **侧栏底部的版本号张冠李戴**：`@deepseek-ai/dsh` 那行过去显示的是**启动器自己的版本**（如 v0.2.2），而不是当前安装的 dsh 版本 —— 让人误以为 dsh 也停在 0.2.2。现在启动器版本并入标题「DSH Starter v0.2.2」，`@deepseek-ai/dsh` 那行改显示真正在用的 dsh 版本，没装时显示「未安装」。
- **Windows 上「文件被占用」的安装失败不再被误报成下载超时**：杀毒软件、编辑器或还在运行的 dsh 攥住 `node_modules` 时，pnpm 报的是 EPERM/EBUSY —— 过去它被套进「下载超时」的模板：提示你去担心网络、还自动挂上一个 600 秒的超时参数重试一次（当然照样失败）。现在会直说：先停掉这个实例、关闭占用该目录的程序再重试。
- **凭据文件的备份不再是「裸奔的明文 token」**：每次保存凭据前，启动器会把旧的 `credentials.yaml` 备份成同目录下的 `.starter-bak` —— 过去这份备份按系统默认权限落成 0644，**同机器上的任何用户都能直接读走你全套明文凭据**（主文件自己是 0600，备份却忘了收紧）。现在备份与凭据主文件权限一致（0600），且主文件自创建起就是 0600，不再有几毫秒的开放窗口。
- **「停止外部实例」不再可能因损坏的进程登记误杀整机进程**：独立进程登记表（`detached.json`）若被写坏，超范围的进程号在过去会被当成负数发给系统 —— 那是「结束本用户全部进程」的语义，桌面上一切都会立刻被杀掉。现在这类进程号会在动手前被拒绝，并给出中文提示（删除该登记文件重开启动器即可）。
